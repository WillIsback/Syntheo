Cette page relie les modules de l'application desktop aux pages de documentation qu'il faut mettre à jour quand ils changent. Pour la pile technique et le flux de capture, voir [Architecture](/architecture). Les plugins Tauri et les paquets `packages/*` ont leurs propres cartes ([/code/plugins](/code/plugins)).

## Vue d'ensemble

| Partie | Chemin | Rôle |
| --- | --- | --- |
| Interface | `apps/desktop/src` | React 19, routage TanStack Router (`routes/`), état Zustand (`store/zustand/`), textes traduits avec Lingui (`i18n/`). |
| Cœur natif | `apps/desktop/src-tauri/src` | Démarrage, ouverture de la base, enregistrement des plugins Tauri, index de recherche, installation de la CLI et des compétences d'agents. |

**Dépendances internes du paquet `@syntheo/desktop`** (`apps/desktop/package.json`) : `@syntheo/changelog`, `db`, `db-react`, `db-tauri`, `editor`, `provider-validation`, `store`, `ui`, `utils`, `design-system` (dev), et les liaisons TypeScript des plugins `contacts`, `db`, `deeplink2`, `detect`, `dictation`, `export`, `fs-sync`, `hooks`, `icon`, `local-api`, `local-auth`, `misc`, `notification`, `opener2`, `permissions`, `relay`, `session`, `settings`, `sfx`, `shortcut`, `store2`, `tantivy`, `template`, `transcription`, `tray`, `windows`.

## Interface : `apps/desktop/src`

### Fenêtres et routes

`routes/` définit une route par fenêtre Tauri. `routeTree.gen.ts` est généré.

| Route | Rôle |
| --- | --- |
| `routes/app/main/_layout*.tsx` | Fenêtre principale : onglets (notes, paramètres, modèles, contacts, dossiers, automatisations…), mise en page dans `main/` et `shared/main/`. |
| `routes/app/note.$sessionId.tsx` | Note ouverte dans sa propre fenêtre. |
| `routes/app/floating-bar.tsx`, `live-caption.tsx` | Barre flottante de réunion et sous-titres en direct (`meeting-float/`). |
| `routes/app/composer.tsx` | Fenêtre de chat rapide (`composer/`). |
| `routes/app/onboarding.tsx` | Premier lancement (`onboarding/`). |
| `routes/app/instruction.tsx` | Écran « continuer dans le navigateur » ; connexion, facturation et intégrations cloud ont disparu. |

Les types d'onglets sont dans `store/zustand/tabs/schema.ts`. Les anciens onglets `calendar` et `task` sont ignorés à la relecture des onglets épinglés (`pinned-persistence.ts`).

Les tests à la racine de `apps/desktop/src` (`no-audio-at-rest`, `stt-on-prem`, `llm-on-prem`, `no-cloud-imports`, `no-telemetry`, `monorepo-scope`, `docs-rgpd`) protègent les garanties décrites dans [Architecture](/architecture). `docs-rgpd.test.ts` lit `docs/conformite/rgpd.md` : un nouveau flux réseau ou stockage doit y être ajouté.
