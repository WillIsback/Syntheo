Cette page relie chaque page de la documentation aux sources qui en déterminent le contenu. Quand vous modifiez une de ces sources, relisez les pages correspondantes et mettez-les à jour dans la même pull request.

<Note>
  Les tests de `apps/cli/src/cli.rs` et `apps/cli/src/mcp/tests.rs` comparent le contrat de la CLI et du serveur MCP à `docs/reference/cli.mdx`, `docs/reference/mcp.mdx` et `skills/syntheo/references/`. Une modification de ce contrat sans mise à jour de la documentation fait échouer la CI.
</Note>

<Note>
  Les reproductions interactives de l'app (`docs/snippets/*.gen.jsx`, générées par `scripts/sync-docs-ui.mjs` depuis `scripts/docs-ui/*.jsx.tpl`) reprennent les couleurs de `packages/design-system/src/tokens.css`, les libellés de `apps/desktop/src/i18n/locales/fr/messages.po` et les icônes de `packages/ui/src/components/icons-*.tsx`. Un changement de couleur, de libellé ou d'icône est repris en relançant le script ; un libellé supprimé fait échouer `apps/desktop/src/docs-ui.test.ts`. Quand la structure d'un écran change, mettez à jour le modèle indiqué dans [Reproductions interactives](#reproductions-interactives).
</Note>
