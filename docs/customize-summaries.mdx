Un compte rendu suit soit le format « Automatique », soit un modèle aux sections fixes. Vous gérez les deux dans la vue **Modèles** : **Paramètres → Mes réunions → « Modèles »**, ou la palette <kbd>Ctrl</kbd> + <kbd>K</kbd>.

La colonne de gauche liste les modèles par groupe : « Automatique », « Favoris », puis un groupe par dossier qui utilise un modèle (nommé comme le dossier), puis « Généraux ». Chaque modèle n'apparaît qu'une fois : un favori reste sous « Favoris ». Utilisez « Rechercher un modèle » pour filtrer la liste ; la recherche porte aussi sur le nom des dossiers.

## Les modèles fournis

Syntheo installe 21 modèles en français.

Quatre modèles Syntheo sont marqués comme favoris et apparaissent sous « Favoris » :

| Modèle | Usage |
| --- | --- |
| Réunion générale | Résumé standard : participants, décisions et actions à suivre. |
| Comité conformité / RGPD | Contexte réglementaire, décisions, points bloquants avant production. |
| Point projet / Sprint | Avancement, blocages, prochaines étapes. |
| Standup équipe | Format court : fait, en cours, bloquants. |

Dix-sept autres modèles couvrent des cas courants : conseil d'administration, séance de brainstorming, lancement client, entretien de découverte client, standup quotidien, point direction, post-mortem d'incident, rendez-vous investisseur, notes de cours, entretien individuel (1:1), entretien annuel, revue de roadmap produit, lancement de projet, appel de découverte commerciale, planification de sprint, rétrospective de sprint et revue de conception technique.

Tous ces modèles sont modifiables. Pour ajouter ou retirer un modèle des favoris, faites un clic droit sur son nom dans la liste et choisissez « Ajouter aux favoris » ou « Retirer des favoris ». Dans l'éditeur, le bouton « Ajouter aux favoris » (ou « Favori ») fait de même.

## Choisir un modèle pour une réunion

Avant la réunion, à l'étape **Préparer**, cliquez sur le type affiché à côté de « Type », dans la fiche de la note (« Automatique » par défaut). Recherchez un modèle avec « Rechercher un type de réunion », puis sélectionnez-le. Le compte rendu suivra ce modèle.

Si la note est rangée dans un dossier qui a un modèle par défaut, le type affiche ce modèle suivi de « — modèle du dossier ». Choisir un autre modèle dans la liste le fixe sur la note.

Après la réunion, à l'étape **Synthèse**, cliquez sur le nom du modèle sous le titre pour ouvrir le sélecteur. Sélectionner un autre modèle remplace le compte rendu par un nouveau, rédigé selon ce modèle. Pour appliquer à nouveau le même modèle, utilisez « Régénérer ». Voir [Notes, comptes rendus et transcriptions](/notes).

## Choisir un modèle par dossier

Donnez un modèle par défaut à un dossier pour que toutes ses réunions suivent le même format.

1. Ouvrez la page du dossier (voir [Dossiers et projets](/folders)).
2. Dans la colonne de droite, sous « Modèle de compte rendu », choisissez un modèle. « Aucun » retire le modèle du dossier.

Ce modèle s'applique aux notes du dossier et de ses sous-dossiers qui n'ont pas de modèle choisi. Un sous-dossier sans modèle hérite de celui du dossier parent le plus proche : la page le rappelle, par exemple « Sans modèle ici, les notes utilisent Point projet / Sprint, celui du dossier Clients. »

Pour rédiger un compte rendu, Syntheo retient le premier modèle disponible dans cet ordre :

1. le modèle choisi au lancement de la synthèse, par exemple avec le sélecteur de l'étape Synthèse ;
2. le modèle choisi sur la note, à l'étape Préparer ;
3. le modèle du dossier de la note, ou de son dossier parent le plus proche ;
4. le modèle marqué « Utiliser par défaut » ;
5. le format « Automatique ».

Un modèle supprimé n'est plus appliqué.

### Ranger une note déjà synthétisée

Si vous rangez une note qui a déjà un compte rendu dans un dossier dont le modèle est différent, Syntheo affiche « Ce dossier utilise le modèle … » : « Régénérer la synthèse avec ce modèle ? La version actuelle reste dans l'historique. » Cliquez sur « Régénérer » pour appliquer le modèle du dossier. Sans clic, le compte rendu ne change pas. Aucune proposition n'apparaît si la note a un modèle choisi ou si son compte rendu suit déjà ce modèle.

## Créer un modèle

1. Ouvrez la vue **Modèles**.
2. Cliquez sur « + Nouveau modèle » en bas de la liste.
3. Donnez un nom et une description (« À quoi sert ce modèle ? »).
4. Sous « Utilisé pour », cliquez sur « + Ajouter » pour indiquer les réunions auxquelles ce modèle est destiné (équipe, rôle, fréquence…), par exemple « Hebdo » ou « Équipe RH ».
5. Sous « Sections », ajoutez des sections avec « + Ajouter une section ». Chaque section a un titre et une consigne d'une ligne : « Décrivez en une ligne ce que Syntheo doit y écrire. »

Pour réordonner les sections, faites glisser la poignée d'une section. Au clavier, placez le focus sur la poignée et utilisez les flèches haut et bas.

Les modifications sont enregistrées au fil de l'eau. Le menu « Plus d'actions » de l'éditeur propose « Utiliser par défaut », « Dupliquer » et « Supprimer ».

### Voir la forme du compte rendu

En haut de l'éditeur, basculez de « Modifier » à « Aperçu ». L'aperçu montre la forme de la synthèse : chaque section avec un exemple de ligne rédigée selon sa consigne.

## Proposer des sections avec l'IA

Dans l'éditeur d'un modèle, le champ « Décrivez la réunion, Syntheo propose les sections… » fait rédiger les sections par votre serveur de synthèse local.

1. Décrivez la réunion en une phrase, par exemple : « Revue mensuelle de sécurité avec l'équipe infrastructure ». Si vous laissez le champ vide, Syntheo part du nom et de la description du modèle.
2. Cliquez sur « Proposer des sections ».
3. Syntheo propose 3 à 6 sections. Relisez-les et ajustez-les.

<Warning>
  Les sections proposées remplacent les sections du modèle ouvert. Le nom, l'icône et la description ne sont remplis que s'ils sont encore vides. Dupliquez d'abord un modèle que vous voulez conserver.
</Warning>

Le bouton reste désactivé tant qu'aucun serveur de synthèse n'est connecté : « Configurez votre serveur de synthèse dans les paramètres pour obtenir des propositions de sections. ». Voir [Configurer la transcription et l'IA](/ai-setup).

## Personnaliser « Automatique »

Le format « Automatique » laisse Syntheo structurer le compte rendu lui-même, sans modèle fixe. Il sert quand aucun modèle ne s'applique à la réunion : ni sur la note, ni sur son dossier, ni par défaut.

1. Ouvrez la vue **Modèles** et sélectionnez **Automatique**.
2. Modifiez le « Format du résumé », puis cliquez sur « Enregistrer ».

Par exemple :

```text
Commencez par les décisions. Listez ensuite les actions avec un responsable et une échéance. Limitez le contexte à trois puces.
```

« Améliorer avec des exemples » vous permet de coller jusqu'à trois comptes rendus que vous aimez (ou de joindre des fichiers Markdown ou texte) : votre modèle de langage en déduit un nouveau format. « Réinitialiser au format par défaut », dans le menu « Actions du modèle », rétablit le format d'origine.

Les notes, la transcription et les participants sont toujours transmis au modèle de langage, quel que soit le format. Le format « Automatique » ne s'applique que lorsque « Automatique » est sélectionné : les autres modèles gardent leurs sections.

Après la génération, les suggestions « Raccourcissez le résumé. » et « Allongez le résumé. » du [chat](/chat) permettent d'ajuster la longueur.

## Améliorer les noms et termes spécialisés

Sous **Paramètres → Écrire → « Dictionnaire »**, ajoutez les noms de collègues, acronymes, noms de produits et termes métier que la transcription reconnaît mal. Syntheo les transmet comme indices à votre serveur de transcription ; leur effet dépend de ce que ce serveur prend en charge.

Le dictionnaire ne remplace pas le bon choix des langues parlées. Voir [Langues](/languages).

## Appliquer vos changements

Les nouveaux comptes rendus utilisent le format sélectionné. Régénérez un ancien compte rendu pour lui appliquer la dernière version d'un modèle ou du format « Automatique ».
