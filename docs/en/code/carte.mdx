This map shows each zone of the code (apps, plugins, crates, packages) as a disc sized by its lines of code, excluding tests and generated files. A line joins two zones when one calls, imports, references, or instantiates the other at least 8 times (8 edges in the index). Hover a zone to light up its neighbors, and click it to see its main dependencies and the documentation page that cites it in the [doc ↔ code mapping](/en/code/doc-map). The data comes from the local CodeGraph index and the zone split of `scripts/menage-lignes.mjs`. The map is regenerated for every minor or major release with `node scripts/code-map.mjs`, after `codegraph index`.
