This page links the desktop app's modules to the documentation pages to update when they change. For the tech stack and the capture flow, see [Architecture](/en/architecture). The Tauri plugins and the `packages/*` packages have their own maps ([/en/code/plugins](/en/code/plugins)).

## Overview

| Part | Path | Role |
| --- | --- | --- |
| Interface | `apps/desktop/src` | React 19, TanStack Router routing (`routes/`), Zustand state (`store/zustand/`), texts translated with Lingui (`i18n/`). |
| Native core | `apps/desktop/src-tauri/src` | Startup, database opening, Tauri plugin registration, search index, installation of the CLI and agent skills. |

**Internal dependencies of the `@syntheo/desktop` package** (`apps/desktop/package.json`): `@syntheo/changelog`, `db`, `db-react`, `db-tauri`, `editor`, `provider-validation`, `store`, `ui`, `utils`, `design-system` (dev), and the TypeScript bindings of the plugins `contacts`, `db`, `deeplink2`, `detect`, `dictation`, `export`, `fs-sync`, `hooks`, `icon`, `local-api`, `local-auth`, `misc`, `notification`, `opener2`, `permissions`, `relay`, `session`, `settings`, `sfx`, `shortcut`, `store2`, `tantivy`, `template`, `transcription`, `tray`, `windows`.

## Native core: `apps/desktop/src-tauri/src`

**Internal dependencies** (`apps/desktop/src-tauri/Cargo.toml`): `crates/brand`, `crates/audio-actual`, `crates/audio-mock` (optional), `crates/db-app`, `crates/db-core`, `crates/host`, `crates/intercept`, `crates/storage`, and the workspace's `tauri-plugin-*` plugins.

## Interface: `apps/desktop/src`

### Windows and routes

`routes/` defines one route per Tauri window. `routeTree.gen.ts` is generated.

| Route | Role |
| --- | --- |
| `routes/app/main/_layout*.tsx` | Main window: tabs (notes, settings, templates, contacts, folders, automations…), layout in `main/` and `shared/main/`. |
| `routes/app/note.$sessionId.tsx` | Note opened in its own window. |
| `routes/app/floating-bar.tsx`, `live-caption.tsx` | Floating meeting bar and live captions (`meeting-float/`). |
| `routes/app/composer.tsx` | Quick chat window (`composer/`). |
| `routes/app/onboarding.tsx` | First launch (`onboarding/`). |
| `routes/app/instruction.tsx` | "Continue in the browser" screen; sign-in, billing and cloud integrations are gone. |

Tab types are in `store/zustand/tabs/schema.ts`. The old `calendar` and `task` tabs are ignored when pinned tabs are read back (`pinned-persistence.ts`).

## Tested guarantees

The tests at the root of `apps/desktop/src` (`no-audio-at-rest`, `stt-on-prem`, `llm-on-prem`, `no-cloud-imports`, `no-telemetry`, `monorepo-scope`, `docs-rgpd`) protect the guarantees described in [Architecture](/en/architecture). `docs-rgpd.test.ts` reads `docs/conformite/rgpd.md`: any new network flow or storage must be added to it.
