This page links each documentation page to the sources that determine its content. When you change one of these sources, review the matching pages and update them in the same pull request.

<Note>
  The tests in `apps/cli/src/cli.rs` and `apps/cli/src/mcp/tests.rs` compare the CLI and MCP server contract against `docs/reference/cli.mdx`, `docs/reference/mcp.mdx` and `skills/syntheo/references/`. Changing this contract without updating the documentation makes CI fail.
</Note>

<Note>
  The interactive reproductions of the app (`docs/snippets/*.gen.jsx`, generated by `scripts/sync-docs-ui.mjs` from `scripts/docs-ui/*.jsx.tpl`) use the colors from `packages/design-system/src/tokens.css`, the labels from `apps/desktop/src/i18n/locales/fr/messages.po` and the icons from `packages/ui/src/components/icons-*.tsx`. A change of color, label or icon is picked up by running the script again; a removed label makes `apps/desktop/src/docs-ui.test.ts` fail. When the structure of a screen changes, update the template listed in [Interactive reproductions](#interactive-reproductions).
</Note>
