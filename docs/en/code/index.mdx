This section describes Syntheo Desktop's code area by area: the role of each app, plugin, crate and package, what it exposes and what it depends on. It helps keep the documentation up to date: when a part of the code changes, these pages show which user pages to review.

For the overall organization and the data flow, read [Architecture](/en/architecture) first.

## Two tools, two uses

| Tool | Use | Access |
| --- | --- | --- |
| **CodeGraph** | Code tasks: find a symbol, follow a call, measure the impact of a change. | Local `.codegraph/` index, `codegraph` MCP server. |
| **Code map (this section)** | Documentation maintenance: know which code determines which documented behavior. | Mintlify pages, `syntheo-docs` MCP server. |

The documentation search MCP server is declared in `.mcp.json` at the repository root:

```bash
claude mcp add --transport http syntheo-docs https://docs.syntheo.studio/mcp
```

## Maintain the map

- A pull request that adds, renames or removes a crate, a plugin, a package or a top-level module updates the page for its area.
- A pull request that changes a visible behavior checks [Doc ↔ code mapping](/en/code/doc-map) and updates the affected user pages.
- Only describe what is present in the code. The writing rules in `docs/AGENTS.md` apply.
