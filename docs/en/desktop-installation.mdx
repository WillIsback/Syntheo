Syntheo Desktop is published for **Linux** (AppImage and `.deb`) and **Windows** (signed `.exe` installer and `.msi`), on x64. macOS packages are not published yet.

All packages are available on the [GitHub Releases](https://github.com/WillIsback/Syntheo/releases/latest) page.

## Choose the right package

| Platform | File (stable name) | Notes |
| --- | --- | --- |
| Linux | [`Syntheo-linux-x86_64.AppImage`](https://github.com/WillIsback/Syntheo/releases/latest/download/Syntheo-linux-x86_64.AppImage) | Portable, no installation. Requires FUSE 2. |
| Linux | [`Syntheo-linux-amd64.deb`](https://github.com/WillIsback/Syntheo/releases/latest/download/Syntheo-linux-amd64.deb) | Debian, Ubuntu, and derivatives. |
| Windows | [`Syntheo-windows-x64-setup.exe`](https://github.com/WillIsback/Syntheo/releases/latest/download/Syntheo-windows-x64-setup.exe) | Signed installer, per-user installation. |
| Windows | [`Syntheo-windows-x64.msi`](https://github.com/WillIsback/Syntheo/releases/latest/download/Syntheo-windows-x64.msi) | For managed deployments. |

The links above always point to the latest version. Each release also publishes the same files under a versioned name, for example `Syntheo_0.4.0_amd64.AppImage` or `Syntheo_0.4.0_x64-setup.exe`.

## Linux

### Install script (AppImage)

```bash
curl -fsSL https://raw.githubusercontent.com/WillIsback/Syntheo/main/scripts/install.sh | bash
```

The script downloads the AppImage of the latest release, checks its SHA256 sum, saves it as `~/.local/bin/Syntheo.AppImage`, and creates the `syntheo` command. Reinstalling replaces the previous version and removes older `Syntheo-<version>.AppImage` files.

Useful options:

- `--version vX.Y.Z` installs a specific version: replace `vX.Y.Z` with a tag from the [Releases](https://github.com/WillIsback/Syntheo/releases) page.
- `--deb` downloads the `.deb` package instead of the AppImage.
- `--to <folder>` changes the installation folder (`~/.local/bin` by default).

If `~/.local/bin` is not in your `PATH`, the script tells you which line to add.

On Arch-based distributions (Omarchy, EndeavourOS, Manjaro), the AppImage needs FUSE 2:

```bash
sudo pacman -S fuse2
```

### Debian and Ubuntu

```bash
curl -fsSL https://raw.githubusercontent.com/WillIsback/Syntheo/main/scripts/install.sh | bash -s -- --deb
sudo apt install ~/.local/bin/Syntheo_*_amd64.deb
```

You can also download [`Syntheo-linux-amd64.deb`](https://github.com/WillIsback/Syntheo/releases/latest/download/Syntheo-linux-amd64.deb) and install it with `sudo apt install ./Syntheo-linux-amd64.deb`.

### Manually downloaded AppImage

```bash
chmod +x ./Syntheo-linux-x86_64.AppImage
./Syntheo-linux-x86_64.AppImage
```

### Black window on Wayland

Syntheo uses WebKitGTK graphics acceleration. If the window stays black (this can happen with some drivers, for example NVIDIA on Wayland), disable DMA-BUF rendering, then, if needed, compositing:

```bash
WEBKIT_DISABLE_DMABUF_RENDERER=1 syntheo
WEBKIT_DISABLE_DMABUF_RENDERER=1 WEBKIT_DISABLE_COMPOSITING_MODE=1 syntheo
```

## Windows

Windows 10 version 2004 (build 19041) or later, or Windows 11, on x64. Syntheo and its transcription program load the Windows DirectML library (`System32\DirectML.dll`) and call `DMLCreateDevice1`, available since DirectML 1.1.0, built into Windows since version 2004; on an earlier version, Syntheo does not start.

### Installer

Download [`Syntheo-windows-x64-setup.exe`](https://github.com/WillIsback/Syntheo/releases/latest/download/Syntheo-windows-x64-setup.exe), then run it. It installs into your user profile, without administrator rights.

The installer and the `.msi` are **signed** (Azure Artifact Signing): Windows attributes them to **William Derue**. SmartScreen may still show a warning on the first versions, while the binary builds its reputation.

### Install script (PowerShell)

```powershell
irm https://raw.githubusercontent.com/WillIsback/Syntheo/main/scripts/install.ps1 | iex
```

The script downloads the installer of the latest release, checks its SHA256 sum against `SHA256SUMS-windows`, and installs it silently (per user, without elevation). For a specific version, replace `vX.Y.Z` with a tag from the [Releases](https://github.com/WillIsback/Syntheo/releases) page:

```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/WillIsback/Syntheo/main/scripts/install.ps1))) -Version vX.Y.Z
```

### MSI

Download [`Syntheo-windows-x64.msi`](https://github.com/WillIsback/Syntheo/releases/latest/download/Syntheo-windows-x64.msi) for a managed installation (GPO, Intune, and so on).

## Verify a package

Each release publishes `SHA256SUMS` (all packages) and `SHA256SUMS-windows`, along with a GitHub provenance attestation.

```bash
sha256sum -c SHA256SUMS --ignore-missing
gh attestation verify Syntheo-linux-x86_64.AppImage -R WillIsback/Syntheo
```

On Windows, compare the output of `Get-FileHash <file>` with the matching line in `SHA256SUMS-windows`.

### Update signatures

For the built-in update, each release also publishes:

- `latest.json`, the manifest the app reads: version, release notes, and for the AppImage and the NSIS installer the installer's address and its signature. It is listed in `SHA256SUMS`;
- `Syntheo_<version>_amd64.AppImage.sig` and `Syntheo_<version>_x64-setup.exe.sig`, the signatures of these two installers.

These signatures use a Tauri (minisign) key specific to Syntheo, separate from Windows code signing. The app embeds the public key and rejects any installer whose signature does not match, or whose signed version differs from the announced version. Key ID: `682D46182EA91D28`. Public key, as set in the app's configuration:

```text
dW50cnVzdGVkIGNvbW1lbnQ6IG1pbmlzaWduIHB1YmxpYyBrZXk6IDY4MkQ0NjE4MkVBOTFEMjgKUldRb0hha3VHRVl0YUF3MmVBV2ZTNlU5Wit4R1hETDlBWmRSSk0wNTZwLzNOVi9YNUtMYVNyUHUK
```

The `.deb` package and the MSI are not signed for updates: the app reports the new version and links to the download page.

## Update

Syntheo checks for updates at startup (on by default) and when you ask in **Settings › Profile**, "Updates" section: "Check for updates". The notification area also offers "Check for Updates…".

- **AppImage and Windows installer (.exe)**: when a newer version exists, a message announces it in the sidebar ("See the update"). In Settings, read what's new, then "Download the update" and "Install and restart". Nothing is installed without your action, and never while a meeting is being recorded. Syntheo checks the installer's signature before installing it (see [Update signatures](#update-signatures)). Your notes and settings are kept.
- **.deb package and MSI**: Syntheo announces the new version and opens the download page; install the new package as you did the first one.

The check reads the `latest.json` file of the latest release on GitHub, then, if you update, downloads the installer from GitHub. No personal data is sent; GitHub sees the computer's IP address. To stop checking at startup, turn off "Check for updates at startup". On a managed computer, the administrator can turn it off with the `automatic_updates` key set to `false` in `managed_settings.json`. Offline or behind a firewall, the startup check fails silently; a manual check shows the error.

The update replaces the AppImage file without renaming it. An AppImage downloaded by hand as `Syntheo_0.7.3_amd64.AppImage` will therefore hold the next version under that name. The install script avoids this by installing it as `Syntheo.AppImage`.

The built-in update works from version 0.7.3 onward. To move from an earlier version to 0.7.3, run the install script again or download the new package from [GitHub Releases](https://github.com/WillIsback/Syntheo/releases/latest).

To remove the app, alone or with all your data, see [Uninstall Syntheo](/en/uninstall).

## Third-party licenses

**Settings › Profile**, "About" section, "Licenses" button: the list of third-party components included in Syntheo (Rust crates, npm packages, ONNX Runtime) and of the transcription models, with their version, their license, and the license texts each component provides. The list is produced when the app is built, from its dependency files, and shows without a connection. The npm packages listed are those shipped in the interface, without the build tools. A license missing from a package's metadata is deduced from its license text, or shown as "Unknown". The search finds a component by the start of its name or by a license identifier ("MIT", "Apache-2.0"). The same section recalls that Syntheo is released under the MIT license and derived from Anarlog (Fastrepl, Inc., MIT), and gives the address of its source code.
