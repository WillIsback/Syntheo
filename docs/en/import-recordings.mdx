You can use Syntheo with a conversation recorded elsewhere:

- import an **audio file** to have your server transcribe it;
- import an existing SRT or VTT **transcript** to get a summary from it.

Everything happens locally: Syntheo reads the files on your computer and uses no online import service.

## Import an audio file

1. On the home screen, click "Start a meeting", or open an empty note.
2. Open the **•••** menu at the top right of the note and choose "Upload audio".
3. Select the file.
4. Keep Syntheo open during transcription.

You can also drag an audio file onto an open note.

Accepted formats: WAV, MP3, OGG, MP4, M4A, FLAC, WebM and AAC.

You follow the progress in the note: "Generating transcript...", the percentage done, then the estimated time left, for example "About 3 min remaining". Click "Stop transcription" to interrupt the import.

The capsule at the bottom of the note also switches to the "Import" state until the end: a progress bar, the percentage, then the time left and the speed-up once they are reliable, for example "~9 min left · ×2.1". While the file is being read, then for the first 30 seconds of transcription and until 5% of the audio is processed, it shows "Estimating…". The estimate then follows the average speed since the transcription started moving, reconnections included: as long as no reconnection has been measured, it stays cautious. While the progress pauses (during a reconnection), the time left doesn't climb back up, and the change once it resumes is smoothed. "Stop" interrupts the import, like "Stop transcription".

Try it: open the ••• menu (1) and choose "Upload audio". The progress appears in the "Transcription" margin (2) and in the capsule (3). In the replica, one second equals one minute of audio.

Audio is not kept in the note. Syntheo chooses how to send the file based on your transcription server's protocol:

- **"OpenAI compatible (realtime and batch)"**: Syntheo sends the file to the `/v1/audio/transcriptions` endpoint, without making a copy. Long or large files are split into several requests.
- **"NVIDIA NeMo-Speech.cpp"**: Syntheo decodes the file in memory, without writing it to disk, and sends it in a single request to `/v1/audio/transcriptions`, with timed words and speakers. A 28-minute recording is transcribed in about a minute on an NVIDIA card. The server reports no progress: during that request, the capsule shows "Transcription in progress…", an animated bar with no percentage and the elapsed time, with "Stop". Beyond 3 hours, the audio goes in several successive requests and the bar moves forward with each one; the speakers of one request are then not linked to those of the previous ones. If the request fails, Syntheo falls back to the real-time stream (WebSocket `/v1/audio/transcriptions/realtime`), with the usual progress, as for a live meeting, up to four times faster than the recording's duration. If the connection drops, Syntheo reconnects and resumes after the last transcribed passage, with no duplicates. If the server rejects the key or the settings, the import stops.

If Syntheo was closed after the server had finished the transcription, the note is completed at the next launch. If that result can't be used, for example because no speech was detected, Syntheo abandons the import instead of retrying it at every launch: "Audio import failed" appears once with the "Open note" button, and the note shows "Transcription failed".

When transcription is done, Syntheo writes a summary if a server is set up in **Settings → Synthesis**.

<Note>
  If your model can transcribe a file neither in batch nor live, the "Upload audio" menu item is grayed out. Click it to show "Can't import this audio" with the cause and the "Transcription settings" button.
</Note>

The "Upload audio" and "Upload transcript" menu items appear only in an empty note, with no transcript and no capture in progress.

## Import a transcript

1. On the home screen, click "Start a meeting", or open an empty note.
2. Open the **•••** menu and choose "Upload transcript".
3. Select a WebVTT (`.vtt`) or SubRip (`.srt`) file.

Syntheo adds the timestamped text to the note, then writes a summary if a summary server is set up and the note does not have one yet.

## If an import does not start

- Check that the file is in a supported format.
- For an audio file, check in **Settings → Transcription** that a model is selected and that "Test connection" succeeds.
- If you are coming from another meeting assistant, export your meetings as SRT or VTT and import each transcript into an empty note (see above).

See [Set up transcription and AI](/en/ai-setup) to set up servers, or [Troubleshooting](/en/troubleshooting) for common errors.
