Le chat de Syntheo répond à vos questions sur la réunion ouverte, cherche dans vos autres réunions et vous aide à préparer le suivi. Il utilise le modèle de langage configuré sous **Paramètres → « Synthèse »**. Sans modèle connecté, le chat vous invite à « Ouvrir les paramètres de l'IA ».

## Poser une question sur la réunion ouverte

1. Ouvrez une note de réunion.
2. Ouvrez le chat : à l'étape Synthèse, cliquez sur « Demander à la note » dans la capsule. À tout moment, le raccourci <Kbd keys="Ctrl+J" /> ouvre et ferme le chat.
3. Posez votre question ou choisissez une suggestion. La réunion ouverte est ajoutée automatiquement au contexte.

Suggestions proposées :

- Pendant une capture : « Résumez les 5 dernières minutes. », « Suggérez la prochaine question à poser. », « Listez les éléments d'action jusqu'à présent. »
- Après la réunion : « Listez les éléments d'action. », « Rédiger un e-mail de suivi. », « Trouvez les décisions clés. »
- Quand un compte rendu existe : « Raccourcissez le résumé. » et « Allongez le résumé. »
- Pour une note rangée dans un dossier : « Préparer l'ordre du jour de la prochaine réunion. ». Cette suggestion n'envoie pas de message : elle ouvre le bloc « Prochaine réunion » du dossier (voir [Dossiers et projets](/fr/folders#prochaine-réunion)).

Vous pouvez aussi demander, par exemple :

- « Compare cette réunion avec la précédente revue de projet. »
- « Retrouve les réunions où nous avons parlé de la date de lancement. »

Pour répondre, le chat peut chercher dans les titres et le contenu de vos réunions, dans vos contacts et dans les documents joints à un dossier.

Les étapes de raisonnement et les outils utilisés sont regroupés dans une ligne « Activité ». Dépliez-la pour les consulter.

Essayez le chat ci-dessous : choisissez une suggestion, tapez `@` puis quelques lettres dans le champ, lancez une automatisation, ou fermez le chat puis rouvrez-le avec « Demander à la note ». « Raccourcissez le résumé. » affiche une modification proposée à la place du compte rendu. Cochez « Sans modèle connecté » pour voir le chat sans modèle de langage. Les repères désignent « Demander à la note » (1), les suggestions (2), le champ (3), « Lancer une automatisation » (4) et « Nouveau chat » (5).

## Interroger un dossier

Sur la page d'un dossier, cliquez sur « Demander au dossier » (ou appuyez sur <Kbd keys="Ctrl+J" />) : le chat s'ouvre avec ce dossier pour contexte.

Depuis la palette <Kbd keys="Ctrl+K" /> filtrée sur un dossier, l'action « Demander au dossier » ouvre une nouvelle conversation dont le champ mentionne déjà le dossier et reprend le texte saisi. Rien n'est envoyé avant que vous validiez. Voir [Dossiers et projets](/fr/folders#chercher-dans-un-dossier).

## Organiser vos réunions

Demandez au chat de lister vos [dossiers](/fr/folders), d'en créer un ou d'y déplacer des réunions. Par exemple : « Range mes revues de lancement dans Projets/Lancement. » Le déplacement change l'emplacement des réunions, pas leur contenu.

Si un enregistrement ou des notes ont atterri sur la mauvaise réunion, le chat peut aussi les déplacer vers une autre réunion existante, à condition que celle-ci n'ait pas encore de transcription.

## Guider le contexte

Le chat utilise automatiquement la réunion ouverte et ajoute d'autres réunions ou personnes si votre demande le nécessite.

Pour ajouter vous-même un élément au contexte, tapez `@` suivi de quelques lettres et choisissez un dossier, une note ou un contact. La liste utilise la même recherche que la palette <Kbd keys="Ctrl+K" />, dans le même ordre : dossiers (avec leur nombre de réunions), notes dont le titre correspond, notes trouvées dans leur contenu, puis contacts. Chaque note affiche son dossier à droite. La liste propose au plus 8 résultats.

Nommez précisément la réunion ou la personne quand plusieurs se ressemblent, ou précisez « Utilise uniquement cette réunion ». Cliquez sur « Nouveau chat » pour repartir d'une conversation vide.

## Modifications de vos notes

Le chat agit de deux façons sur vos notes :

- **Réécriture d'un compte rendu ou d'un mémo** : le chat propose un remplacement complet. Pour un compte rendu, la proposition s'affiche à sa place, à l'étape Synthèse : le texte retiré est barré, le texte ajouté est surligné. Choisissez « Appliquer au résumé » ou « Refuser ». Rien n'est modifié sans votre accord.
- **Correction ponctuelle** (« ce n'est pas X mais Y ») : le chat remplace directement le texte exact dans le compte rendu, le titre ou la transcription.

Pour corriger vous-même la transcription ou réattribuer un locuteur, voir [Notes, comptes rendus et transcriptions](/fr/notes).

## Construire une automatisation

Dans la vue Automatisations, le chat s'affiche à droite de l'éditeur et dispose d'outils propres : il crée l'automatisation ou modifie celle qui est ouverte (nom, déclencheur, étapes). Il ne l'active jamais, et une étape avancée (webhook ou commande) n'est ajoutée qu'après votre confirmation dans l'éditeur. Voir [Construire une automatisation avec le chat](/fr/automations#construire-une-automatisation-avec-le-chat).

## Confidentialité

Le chat envoie votre question et le contexte nécessaire au serveur de modèle de langage que vous avez configuré, et à lui seul. Si ce serveur tourne sur votre machine ou sur votre réseau, ces données ne quittent pas votre infrastructure. Le chat n'effectue aucune recherche sur le web.

Voir [Données et confidentialité](/fr/data-and-privacy).
