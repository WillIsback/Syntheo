Cette carte montre chaque zone du code (applications, plugins, crates, paquets) sous la forme d'un disque dont la taille suit le nombre de lignes de code, hors tests et fichiers générés. Un trait relie deux zones quand l'une appelle, importe, référence ou instancie l'autre au moins 8 fois (8 arêtes de l'index). Survolez une zone pour allumer ses voisines, et cliquez dessus pour voir ses dépendances principales et la page de documentation qui la cite dans la [correspondance doc ↔ code](/fr/code/doc-map). Les données viennent de l'index local CodeGraph et du découpage en zones de `scripts/menage-lignes.mjs`. La carte est régénérée à chaque version mineure ou majeure avec `node scripts/code-map.mjs`, après `codegraph index`.
