Syntheo Desktop est publié pour **Linux** (AppImage et `.deb`) et **Windows** (installeur `.exe` signé et `.msi`), en x64. Les paquets macOS ne sont pas publiés pour l'instant.

Tous les paquets sont disponibles sur la page [GitHub Releases](https://github.com/WillIsback/Syntheo/releases/latest).

## Choisir le bon paquet

| Plateforme | Fichier (nom stable) | Remarques |
| --- | --- | --- |
| Linux | [`Syntheo-linux-x86_64.AppImage`](https://github.com/WillIsback/Syntheo/releases/latest/download/Syntheo-linux-x86_64.AppImage) | Portable, sans installation. Nécessite FUSE 2. |
| Linux | [`Syntheo-linux-amd64.deb`](https://github.com/WillIsback/Syntheo/releases/latest/download/Syntheo-linux-amd64.deb) | Debian, Ubuntu et dérivées. |
| Windows | [`Syntheo-windows-x64-setup.exe`](https://github.com/WillIsback/Syntheo/releases/latest/download/Syntheo-windows-x64-setup.exe) | Installeur signé, installation par utilisateur. |
| Windows | [`Syntheo-windows-x64.msi`](https://github.com/WillIsback/Syntheo/releases/latest/download/Syntheo-windows-x64.msi) | Pour les déploiements gérés. |

Les liens ci-dessus pointent toujours vers la dernière version. Chaque release publie aussi les mêmes fichiers sous un nom versionné, par exemple `Syntheo_0.4.0_amd64.AppImage` ou `Syntheo_0.4.0_x64-setup.exe`.

## Linux

### Script d'installation (AppImage)

```bash
curl -fsSL https://raw.githubusercontent.com/WillIsback/Syntheo/main/scripts/install.sh | bash
```

Le script télécharge l'AppImage de la dernière release, vérifie sa somme SHA256, l'enregistre sous `~/.local/bin/Syntheo.AppImage` et crée la commande `syntheo`. Une réinstallation remplace la version précédente et retire les anciens fichiers `Syntheo-<version>.AppImage`.

Options utiles :

- `--version vX.Y.Z` installe une version précise : remplacez `vX.Y.Z` par une étiquette de la page [Releases](https://github.com/WillIsback/Syntheo/releases).
- `--deb` télécharge le paquet `.deb` au lieu de l'AppImage.
- `--to <dossier>` change le dossier d'installation (par défaut `~/.local/bin`).

Si `~/.local/bin` n'est pas dans votre `PATH`, le script vous indique la ligne à ajouter.

Sur les distributions basées sur Arch (Omarchy, EndeavourOS, Manjaro), l'AppImage a besoin de FUSE 2 :

```bash
sudo pacman -S fuse2
```

### Debian et Ubuntu

```bash
curl -fsSL https://raw.githubusercontent.com/WillIsback/Syntheo/main/scripts/install.sh | bash -s -- --deb
sudo apt install ~/.local/bin/Syntheo_*_amd64.deb
```

Vous pouvez aussi télécharger [`Syntheo-linux-amd64.deb`](https://github.com/WillIsback/Syntheo/releases/latest/download/Syntheo-linux-amd64.deb) et l'installer avec `sudo apt install ./Syntheo-linux-amd64.deb`.

### AppImage téléchargée à la main

```bash
chmod +x ./Syntheo-linux-x86_64.AppImage
./Syntheo-linux-x86_64.AppImage
```

### Fenêtre noire sous Wayland

Syntheo utilise l'accélération graphique de WebKitGTK. Si la fenêtre reste noire (cela peut arriver avec certains pilotes, par exemple NVIDIA sous Wayland), désactivez le rendu DMA-BUF, puis, si besoin, la composition :

```bash
WEBKIT_DISABLE_DMABUF_RENDERER=1 syntheo
WEBKIT_DISABLE_DMABUF_RENDERER=1 WEBKIT_DISABLE_COMPOSITING_MODE=1 syntheo
```

## Windows

Windows 10 version 2004 (build 19041) ou plus récent, ou Windows 11, en x64. Syntheo et son programme de transcription chargent la bibliothèque DirectML de Windows (`System32\DirectML.dll`) et appellent `DMLCreateDevice1`, disponible depuis DirectML 1.1.0, intégrée à Windows depuis la version 2004 ; sur une version antérieure, Syntheo ne démarre pas.

### Installeur

Téléchargez [`Syntheo-windows-x64-setup.exe`](https://github.com/WillIsback/Syntheo/releases/latest/download/Syntheo-windows-x64-setup.exe), puis lancez-le. L'installation se fait dans votre profil utilisateur, sans droits administrateur.

L'installeur et le `.msi` sont **signés** (Azure Artifact Signing) : Windows les attribue à **William Derue**. SmartScreen peut encore afficher un avertissement sur les premières versions, le temps que la réputation du binaire se construise.

### Script d'installation (PowerShell)

```powershell
irm https://raw.githubusercontent.com/WillIsback/Syntheo/main/scripts/install.ps1 | iex
```

Le script télécharge l'installeur de la dernière release, vérifie sa somme SHA256 avec `SHA256SUMS-windows` et l'installe en mode silencieux (par utilisateur, sans élévation). Pour une version précise, remplacez `vX.Y.Z` par une étiquette de la page [Releases](https://github.com/WillIsback/Syntheo/releases) :

```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/WillIsback/Syntheo/main/scripts/install.ps1))) -Version vX.Y.Z
```

### MSI

Téléchargez [`Syntheo-windows-x64.msi`](https://github.com/WillIsback/Syntheo/releases/latest/download/Syntheo-windows-x64.msi) pour une installation gérée (GPO, Intune, etc.).

## Vérifier un paquet

Chaque release publie `SHA256SUMS` (tous les paquets) et `SHA256SUMS-windows`, ainsi qu'une attestation de provenance GitHub.

```bash
sha256sum -c SHA256SUMS --ignore-missing
gh attestation verify Syntheo-linux-x86_64.AppImage -R WillIsback/Syntheo
```

Sous Windows, comparez le résultat de `Get-FileHash <fichier>` avec la ligne correspondante de `SHA256SUMS-windows`.

### Signatures de mise à jour

Pour la mise à jour intégrée, chaque release publie aussi :

- `latest.json`, le manifeste lu par l'application : version, notes de version, et pour l'AppImage et l'installeur NSIS l'adresse de l'installeur et sa signature. Il figure dans `SHA256SUMS` ;
- `Syntheo_<version>_amd64.AppImage.sig` et `Syntheo_<version>_x64-setup.exe.sig`, les signatures de ces deux installeurs.

Ces signatures utilisent une clé Tauri (minisign) propre à Syntheo, distincte de la signature de code Windows. L'application embarque la clé publique et refuse tout installeur dont la signature ne correspond pas, ou dont la version signée diffère de la version annoncée. Identifiant de la clé : `682D46182EA91D28`. Clé publique, telle qu'inscrite dans la configuration de l'application :

```text
dW50cnVzdGVkIGNvbW1lbnQ6IG1pbmlzaWduIHB1YmxpYyBrZXk6IDY4MkQ0NjE4MkVBOTFEMjgKUldRb0hha3VHRVl0YUF3MmVBV2ZTNlU5Wit4R1hETDlBWmRSSk0wNTZwLzNOVi9YNUtMYVNyUHUK
```

Le paquet `.deb` et le MSI ne sont pas signés pour la mise à jour : l'application signale la nouvelle version et renvoie vers la page de téléchargement.

## Mettre à jour

Syntheo recherche les mises à jour au démarrage (réglage activé par défaut) et quand vous le demandez dans **Paramètres › Profil**, section « Mises à jour » : « Rechercher des mises à jour ». La zone de notification propose aussi « Rechercher des mises à jour… ».

- **AppImage et installeur Windows (.exe)** : quand une version plus récente existe, un message l'annonce dans la barre latérale (« Voir la mise à jour »). Dans les Paramètres, lisez ses nouveautés, puis « Télécharger la mise à jour » et « Installer et redémarrer ». Rien n'est installé sans votre action, et jamais pendant l'enregistrement d'une réunion. Syntheo vérifie la signature de l'installeur avant de l'installer (voir [Signatures de mise à jour](#signatures-de-mise-à-jour)). Vos notes et réglages sont conservés.
- **Paquet .deb et MSI** : Syntheo annonce la nouvelle version et ouvre la page de téléchargement ; installez le nouveau paquet comme le premier.

La vérification lit le fichier `latest.json` de la dernière release sur GitHub, puis, si vous mettez à jour, télécharge l'installeur depuis GitHub. Aucune donnée personnelle n'est envoyée ; GitHub voit l'adresse IP du poste. Pour ne plus rien vérifier au démarrage, désactivez « Rechercher les mises à jour au démarrage ». Sur un poste géré, l'administrateur peut la désactiver avec la clé `automatic_updates` à `false` du fichier `managed_settings.json`. Hors ligne ou derrière un pare-feu, la vérification au démarrage échoue sans message ; une recherche manuelle affiche l'erreur.

La mise à jour remplace le fichier de l'AppImage sans le renommer. Une AppImage téléchargée à la main sous le nom `Syntheo_0.7.3_amd64.AppImage` contiendra donc la version suivante en gardant ce nom. Le script d'installation évite ce piège en l'installant sous `Syntheo.AppImage`.

La mise à jour intégrée fonctionne à partir de la version 0.7.3. Pour passer d'une version antérieure à la 0.7.3, relancez le script d'installation ou téléchargez le nouveau paquet depuis [GitHub Releases](https://github.com/WillIsback/Syntheo/releases/latest).

Pour retirer l'application, seule ou avec toutes vos données, voir [Désinstaller Syntheo](/fr/uninstall).

## Licences des composants tiers

**Paramètres › Profil**, section « À propos », bouton « Licences » : la liste des composants tiers inclus dans Syntheo (crates Rust, paquets npm, ONNX Runtime) et des modèles de transcription, avec leur version, leur licence et le texte des licences fournis par chaque composant. La liste est produite à la construction de l'application, à partir de ses fichiers de dépendances, et s'affiche sans connexion. La même section rappelle que Syntheo est distribué sous licence MIT et dérivé d'Anarlog (Fastrepl, Inc., MIT).

## macOS

Les paquets macOS ne sont pas publiés pour l'instant. Pour compiler l'application vous-même, suivez [Construire depuis les sources](https://github.com/WillIsback/Syntheo/blob/main/CONTRIBUTING.md#construire-depuis-les-sources) dans `CONTRIBUTING.md`.
